Design a mobile app UI for FocusVault - a distraction-blocking/focus app.

STYLE:
- Dark theme, glass morphism
- Colors: Purple #7C3AED, Teal #14B8A6, Amber #F59E0B, Black #000000
- SF Pro / Inter fonts
- 8px grid, 16px card radius
- Minimalist, trustworthy (like Stripe + Apple Health)

SCREENS (10 total):

1. ONBOARDING (4 screens):
   - Welcome: Logo + "Built for day 45, not day 1" + Start button
   - Screen Time: Large circular stat + top 5 apps
   - Why: 5 emoji cards (💼😴❤️🧘📚) + text input
   - First Session: Duration picker + mode selector + Start

2. HOME:
   - Streak card (🔥 15 days)
   - Mode pills (Shallow|Deep|Hardcore)
   - Circular duration picker (5-60 min)
   - "Start Session" button (hold 2 sec)

3. ACTIVE SESSION:
   - Huge timer ring (42:18 remaining)
   - Glass card (mode, start time, XP)
   - Unlock button (red) or "Locked 🔒"

4. COMPLETE:
   - Confetti animation
   - "+450 XP" count-up
   - "Level 7→8!" with burst
   - Streak update (🔥 16 days)
   - Achievement badge (if unlocked)

5. ANALYTICS:
   - Time filter (Week|Month|All)
   - 4 stat cards (Total, Streak, Level, XP)
   - Bar chart (7 days)
   - Session history list

6. PROFILE:
   - Avatar + level badge
   - Accountability partner card
   - Subscription status
   - Settings list
   - Danger zone (red)

7. UNLOCK REQUEST (2 views):
   - User: "Are you sure?" + reason input + Send to Partner
   - Partner: Request details + Approve/Deny buttons

8. SCHEDULED BLOCKS:
   - List of recurring sessions
   - "Can't edit (23h)" lock indicator
   - + Create button

9. ACHIEVEMENTS:
   - Badge grid (3 cols)
   - Selected badge detail below

10. SETTINGS:
    - Notifications, Blocked Apps, Privacy

INTERACTIONS:
- Hold-to-start (2 sec circular progress)
- Swipe-to-minimize active session
- Streak repair animation (healing cracks)

TAB BAR:
🏠 Home | 📊 Stats | 🏆 Achievements | 👤 Profile

- React Native code (Expo + NativeWind)
